# 剑冢荒原 V03 美术检查

本次对照 V02 的同机位 Unity 实景，检查自然岩石、地表反光、重点造型与全图通行范围。

- 实景内容。检查地面剑群、坡顶主剑正面与侧面，以及自然散石。
- 本轮修正和复查。重建六种散剑轮廓，变化刃长、刃宽、护格、剑首与倾斜。主剑改直刃、短护格、玉饰与缠柄，残环两侧补岩座。
- 美术说明。剑型参照馆藏轮廓和构造做游戏化处理，主剑采用夸张尺度。
- 工程记录见 [Unity 验证](Unity验证.txt) 和 [最终包复验](Unity包复验.txt)。可见模型共 77,572 三角面。

实景证据见 Previews 目录。01 是总览，02 是默认机位，03 起为其他观察机位。目标设备帧率和项目专用寻路待接入后实测。

独立旧版工程里已放置的 V02 剑冢预制体实例，经原生导入 V03 包后仍保有预制体连接，并更新为 112 把散剑和六种轮廓。
