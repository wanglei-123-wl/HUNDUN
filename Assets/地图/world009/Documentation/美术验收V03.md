# 雷泽禁地 V03 美术检查

本次对照 V02 的同机位 Unity 实景，检查自然岩石、地表反光、重点造型与全图通行范围。

- 实景内容。检查玄武岩岸线、湖面、石堤及遗迹。
- 本轮修正和复查。打散柱石与岸石剖面，压低持续补光。地面和石面使用哑光，分开检查水面与雷光。
- 美术说明。水面保留水体反射，雷暴保留时变照明。
- 工程记录见 [Unity 验证](Unity验证.txt) 和 [最终包复验](Unity包复验.txt)。可见模型共 59,304 三角面。

实景证据见 Previews 目录。01 是总览，02 是默认机位，03 起为其他观察机位。目标设备帧率和项目专用寻路待接入后实测。
