# 雷泽禁地 world009 · V05

本轮把东湖岸边作为重点样段，以角色高度核对湿岩、浅水、芦苇和雷暴下的远景。地图 400 × 400 米，可见 FBX 共 406,059 三角面。

| 检查项 | 结论与证据 |
| --- | --- |
| 构图与天气 | 通过。02、06 为同机位的雷闪与平时效果。木栈桥侧看用 04，主石堤和北平台用 03、05。 |
| 水体与落水 | 通过。运行时镜像相机反射眼前水域的岩岸、遗迹和闪电。实际 Play 模式移动相机后复测。两级落水拆为宽窄不同的流束，逐列检查末端在水域内。 |
| 湿岩、桥面和植物 | 通过。岩面增加实际层片断面、细裂纹与苔痕，受潮区按噪声分布轻微提亮。桥面保持哑光。修复首轮相机贴住草叶的问题，芦苇用细化的三维茎叶配透明穗丝，浅水浮叶保留叶脉。 |
| 通行与边界 | 通过。Unity 验证三条路线、1,178 步胶囊移动、366 个路肩探测、两处桥面及四周空气墙。 |
| 导入与旧版更新 | 通过。FBX 回读、独立 URP 项目导入和 V04 实例原位升级详见工程记录。 |
| 目标设备性能与项目寻路 | 未验证，验收在独立 Unity 2022.3 / URP 14 测试工程完成。 |
