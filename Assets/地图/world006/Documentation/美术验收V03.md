# 终末大道 V03 美术检查

本次对照 V02 的同机位 Unity 实景，检查自然岩石、地表反光、重点造型与全图通行范围。

- 实景内容。检查门洞下长距离路面、反向视角、路肩及贴地机位。
- 本轮修正和复查。将湿度改为地面深浅变化，降低积水叠色亮度，去除镜面和随视角转白的效果。自然散石更新，建筑石构保留砌筑轮廓。
- 美术说明。路面通过颜色和法线表现潮湿、裂纹和磨损。
- 工程记录见 [Unity 验证](Unity验证.txt) 和 [最终包复验](Unity包复验.txt)。可见模型共 74,086 三角面。

实景证据见 Previews 目录。01 是总览，02 是默认机位，03 起为其他观察机位。目标设备帧率和项目专用寻路待接入后实测。

同机位 02 的左下路面区域取横向 1.5% 至 29%、纵向 74% 至 98%。8 位截图亮度超过 200 的像素占比由 V02 的 14.14% 降至 V03 的 0.10%。
