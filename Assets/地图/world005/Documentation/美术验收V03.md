# 药灵谷 V03 美术检查

本次对照 V02 的同机位 Unity 实景，检查自然岩石、地表反光、重点造型与全图通行范围。

- 实景内容。检查溪边、上游坡地、石桥底和沿桥面观察的低机位。
- 本轮修正和复查。取消坡地、桥面和岩石的镜面高光，移除在桥板和岸石上形成热点的近距离补光。岸边散石更换横截面和偏心顶部，露水岩石的基底向下延伸到河床。
- 美术说明。溪水仍有水面反射。远坡植被和山体细节延续现有布局。
- 工程记录见 [Unity 验证](Unity验证.txt) 和 [最终包复验](Unity包复验.txt)。可见模型共 93,777 三角面。

实景证据见 Previews 目录。01 是总览，02 是默认机位，03 起为其他观察机位。目标设备帧率和项目专用寻路待接入后实测。
